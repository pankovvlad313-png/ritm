## Что нового

- Интерактивное обучение из 7 шагов с учебной неделей: создание дела, частота и дни, распределение, закрепление, перемешивание и отметки выполнения.
- Учебные примеры не меняют реальные дела и расписание. Обучение появляется один раз, его можно повторить из меню или настроек.
- Проверка новых версий при запуске и раз в 6 часов, фоновая загрузка обновлений из GitHub Releases.
- Кнопка «Перезапустить и обновить», установка скачанного обновления при закрытии приложения, ручная проверка в настройках и меню «Справка».
- Данные и отметки сохраняются в прежнем профиле `%APPDATA%\Ritm`.

## Переход с 1.0.0

В версии 1.0.0 механизма автоматического обновления нет. Один раз скачайте и установите `Ritm-Setup-1.1.0-x64.exe` поверх неё. Удалять старую версию или её данные не нужно. Начиная с 1.1.0 следующие версии будут загружаться автоматически при наличии интернета.

На случай переноса на другой компьютер в настройках по-прежнему есть резервная копия JSON.

Установщик без цифровой подписи. Обновления скачиваются по HTTPS из этого репозитория; целостность проверяется по SHA512. Файлы `latest.yml` и `.blockmap` нужны механизму обновления — пользователю достаточно `.exe`.
