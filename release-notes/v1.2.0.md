## Что нового

- Напоминания Windows перед началом дел и утренняя сводка. Включаются в настройках; работу можно продолжать в трее при закрытом окне. После перезагрузки компьютера откройте Ритм. Для полного выхода — «Файл → Выйти».
- Свободные часы, лимит минут и количество дел отдельно для каждого дня недели. Для дела можно указать точное начало; автоматическое распределение исключает пересечения.
- «Перенести пропущенные»: просмотр предложений на 30 дней вперёд, учёт обычного расписания будущих недель, ограничений и интервалов. Выбранные повторы переносятся и закрепляются. Перенос можно отменить.
- «Сегодня мало сил»: временное уменьшение дневного лимита вдвое с отменой. Выполненные, закреплённые и прошлые записи сохраняются.
- «Почему здесь?» у каждого дела и подробные причины, почему повторы не поместились.
- Автоматические резервные копии на диске: при запуске и изменениях, не чаще раза в час, последние 30 версий. Ручная копия и восстановление из истории. Перед восстановлением сохраняется текущее состояние.
- Экспорт календаря со временем начала и окончания.
- Веб-версия также поддерживает часы, перенос и историю до 10 копий в браузере. Уведомления Windows работают в установленном приложении.

## Обновление

В 1.1.0 откройте «Настройки → Проверить обновления». После загрузки нажмите «Перезапустить и обновить» либо выйдите через «Файл → Выйти». Данные сохраняются в прежнем профиле `%APPDATA%\Ritm`.

Для 1.0.0 нужно один раз установить этот `.exe` поверх старого приложения. Удалять данные не нужно.

Напоминания включаются пользователем в настройках. Windows может скрывать их в режиме «Не беспокоить»; есть кнопка тестового уведомления. Автозапуск после входа в Windows и синхронизация между устройствами в этот выпуск не входят.

Копии находятся на этом компьютере, в `%APPDATA%\Ritm\backups`. Для переноса на другое устройство используйте JSON. Установщик без цифровой подписи; файлы обновления передаются по HTTPS и проверяются по SHA512.
