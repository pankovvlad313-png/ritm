# Ритм

## Windows-установщик (ветка windows-installer)

В этой ветке приложение упаковано в Electron и работает без интернета. Для Windows 10/11 x64 создаётся `Ritm-Setup-1.2.0-x64.exe`: мастер установки для текущего пользователя, выбор папки, ярлыки на рабочем столе и в меню Пуск, удаление через настройки Windows. При удалении программы данные не стираются автоматически.

Готовый установщик доступен всем без входа в аккаунт на [странице последнего релиза](https://github.com/pankovvlad313-png/ritm/releases/latest). Копия сборки и SHA256 доступны в **Actions → Windows installer → успешный запуск → Artifacts → Ritm-Windows-x64**. Сборка запускается автоматически при изменениях этой ветки. Артефакт хранится 90 дней.

Начиная с 1.1.0 встроены автоматические обновления из GitHub Releases. Проверка выполняется через 15 секунд после запуска и раз в 6 часов. Обновление скачивается в фоне и устанавливается при закрытии программы; можно нажать «Перезапустить и обновить» или вручную проверить обновления в настройках и меню «Справка». Профиль `%APPDATA%\Ritm` и данные сохраняются. Установщик пока не подписан сертификатом издателя; используется HTTPS и проверка целостности SHA512.

**Пользователям 1.0.0:** один раз установите [новую версию из Releases](https://github.com/pankovvlad313-png/ritm/releases/latest) поверх старой. В 1.0.0 кода обновления нет, поэтому автоматически доставить ей эту функцию невозможно.

### Интерактивное обучение

При первом запуске 1.1.0 появляется практика из 7 шагов. Учебная неделя хранится отдельно от реального расписания. Создайте дело, выберите частоту и дни, соберите неделю, закрепите повтор, перемешайте и отметьте выполнение. Обучение можно пропустить и запустить снова из меню «Обучение» или настроек.

### Выпуск следующих обновлений

Повышайте `version` в `package.json` и обновляйте `package-lock.json`; заметки можно добавить в `release-notes/vX.Y.Z.md`. Отправка в `windows-installer` запускает тесты, сборку, проверку упакованной программы и публикацию нового стабильного релиза с установщиком, `latest.yml` и `.blockmap`. Уже опубликованная версия не перезаписывается. Все файлы обновления публикуются из одной проверенной сборки.

### Запуск и сборка на Windows

Нужен Node.js 24 с npm:

```sh
npm ci
npm test
npm start
npm run build:win
```

Файлы установщика появляются в `release/`. Дополнительная проверка собранной программы: `node desktop/smoke.cjs --packaged`.

Данные настольной версии сохраняются отдельно в `%APPDATA%\Ritm`. Для переноса дел из браузера скачайте резервную копию JSON в настройках сайта и загрузите её в настройках настольного приложения. Начиная с 1.2.0 есть системные напоминания Windows, работа в трее, свободные часы, нагрузка по дням, перенос пропусков и автоматические копии. После перезагрузки компьютера откройте Ритм; напоминания включаются в настройках. Подробнее: [заметки 1.2.0](release-notes/v1.2.0.md).

Основная ветка `main` продолжает публиковать веб-версию на GitHub Pages. Установщик содержит локальные файлы приложения, системный шрифт и собственное окно; загрузка сайта из интернета не требуется.

Личный конструктор недельного расписания на русском языке. Работает без сервера и сборки.

## Возможности

- Случайное распределение дел по дням с ограничением нагрузки.
- Частота от 1 до 7 раз в неделю или каждые N дней от заданной даты.
- Подходящие дни, перерывы между повторениями и приоритеты.
- Отметки выполнения, закрепление, пауза и отмена перемешивания.
- Статистика, резервная копия JSON и экспорт недели в календарь ICS.
- Адаптивный интерфейс.

Данные хранятся в localStorage текущего браузера. На GitHub не отправляются. При смене адреса сайта перенесите дела через резервную копию в настройках. Встроенных push-уведомлений нет; напоминания можно настроить после импорта событий в календарь.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Сохраните. GitHub автоматически публикует изменения при обновлении ветки. Файл .nojekyll отключает обработку Jekyll.

## Проверка

Нужен Node.js. Зависимостей нет.

```sh
node --check app.js
node --check planner.js
node test-planner.cjs
```

Тест проверяет 300 случайных расписаний, лимиты, частоту, разрешённые дни, перерывы, интервалы, закреплённые дела и невозможные ограничения.

## Файлы

- index.html — оболочка приложения.
- style.css — стили. Manrope загружается из Google Fonts; при недоступности используется системный шрифт.
- planner.js — алгоритм распределения.
- app.js — интерфейс и локальное хранение.
