# Ритм

Личный конструктор недельного расписания на русском языке. Работает без сервера и сборки.

## Возможности

- Случайное распределение дел по дням с ограничением нагрузки.
- Частота от 1 до 7 раз в неделю или каждые N дней от заданной даты.
- Подходящие дни, перерывы между повторениями и приоритеты.
- Отметки выполнения, закрепление, пауза и отмена перемешивания.
- Статистика, резервная копия JSON и экспорт недели в календарь ICS.
- Адаптивный интерфейс.

Данные хранятся в localStorage текущего браузера. На GitHub не отправляются. При смене адреса сайта перенесите дела через резервную копию в настройках. Встроенных push-уведомлений нет; напоминания можно настроить после импорта событий в календарь.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Сохраните. GitHub автоматически публикует изменения при обновлении ветки. Файл .nojekyll отключает обработку Jekyll.

## Проверка

Нужен Node.js. Зависимостей нет.

```sh
node --check app.js
node --check planner.js
node test-planner.cjs
```

Тест проверяет 300 случайных расписаний, лимиты, частоту, разрешённые дни, перерывы, интервалы, закреплённые дела и невозможные ограничения.

## Файлы

- index.html — оболочка приложения.
- style.css — стили. Manrope загружается из Google Fonts; при недоступности используется системный шрифт.
- planner.js — алгоритм распределения.
- app.js — интерфейс и локальное хранение.
